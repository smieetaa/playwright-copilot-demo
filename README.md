# Playwright + GitHub Copilot Demo

> Companion repo for the YouTube tutorial: **"I automated my QA testing with AI — GitHub Copilot + Playwright changed everything"**

This repo demonstrates how to use GitHub Copilot to generate, complete, and fix Playwright tests — with minimal manual coding.

---

## What's in this repo

| File | What it demonstrates |
|------|----------------------|
| `pages/LoginPage.ts` | Page Object Model class — generated by Copilot Chat (video SS#3, SS#4) |
| `tests/login.spec.ts` | Full login test suite — generated by Copilot Chat (video SS#6, SS#7) |
| `tests/checkout.spec.ts` | Inline autocomplete demo — Copilot completes from a comment (video SS#5) |
| `tests/login.broken.spec.ts` | Intentionally broken test — used to demo Copilot fixing failures (video SS#9) |
| `.github/workflows/playwright.yml` | CI/CD pipeline — generated by Copilot Chat (video SS#10) |

## Getting started

```bash
# 1. Clone the repo
git clone https://github.com/YOUR_USERNAME/playwright-copilot-demo
cd playwright-copilot-demo

# 2. Install dependencies
npm install

# 3. Install Playwright browsers
npx playwright install

# 4. Run all tests
npm test

# 5. View the HTML report
npm run report
```

## The 3 Copilot prompts used in the video

### Prompt 1 — Generate a full test file (Copilot Chat)
```
Write a Playwright test in TypeScript that navigates to a login page,
enters an email and password, clicks the login button, and asserts that
the dashboard heading is visible. Use page object model structure with
a separate LoginPage class and a test file that imports it. Include
locators using best practice selectors.
```

### Prompt 2 — Inline autocomplete trigger (type directly in your .spec.ts file)
```typescript
// test that the checkout button is disabled when the cart is empty
```
Press Enter and wait — Copilot suggests the full test body. Press Tab to accept.

### Prompt 3 — Fix a failing test (Copilot Chat)
```
This Playwright test is failing with the following error. Identify what
is wrong and provide the corrected code with an explanation of the fix:

[paste your terminal error output here]
```

## CI/CD

Every push to `main` and every pull request automatically runs the full test suite via GitHub Actions. The HTML report is uploaded as an artifact after each run.
